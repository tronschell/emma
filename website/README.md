# Emma website

Public landing page for Emma. The site is self-contained in this directory.

## Development

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Checks

```sh
npm run format:check
npm run lint
npm run typecheck
npm run build
```

Run all checks with `npm run check`. The production output is written to `dist/`.
