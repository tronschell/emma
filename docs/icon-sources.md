# Integration icon sources

Emma uses neutral monograms by default. Vendor marks are bundled only when an
official kit grants the intended product-reference use; repository code licenses
do not automatically license trademarks.

public product-icon kit during review. Keep neutral marks for those integrations
until the owner supplies permission and an official asset.
